How to use
  • 1
    Click the AudiTex icon
    Click the extension icon in the toolbar on any webpage to start reading.
  • 2
    Or select text → right-click
    Highlight any text, right-click, and choose “Read aloud with AudiTex”. Works on PDFs too.
  • 3
    Control playback from the floating widget
    Pause, change voice, or adjust speed using the circle widget that appears on the page.
